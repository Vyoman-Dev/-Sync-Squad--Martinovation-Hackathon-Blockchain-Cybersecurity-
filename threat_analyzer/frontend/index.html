DroidGuard Binary Inspection Methodology

Android APKs contain compiled Android Binary XML (AndroidManifest.xml) and Dalvik bytecode (classes*.dex). Plain text readers fail because characters are encoded in binary UTF-16LE and ASCII string pools with intervening null bytes.

DroidGuard utilizes an in-memory byte-stream parser that sweeps across memory chunks to rebuild valid tokens, matching declared permissions and sensitive API calls directly inside your browser.

Threat Scoring Thresholds:
0 - 29 (SAFE): Normal production permissions, clean API footprint.
30 - 64 (SUSPICIOUS): Screen overlay, boot startup triggers, aggressive adware markers.
65 - 100 (MALICIOUS): Accessibility service hijack, Dynamic Dex loading, SMS interception, root exploits.
